# Política de Privacidade
Última atualização: 10/10/2026

## 1. Informações que Armazenamos
- Coletamos IDs de utilizador, servidor, categoria, canais e mensagem para processar comandos e fornecer serviços personalizados.
- Conteúdo das Mensagens: Podemos armazenar temporariamente o conteúdo para realizar as funções solicitadas.
- Metadados: Outras informações como permissões e cargos podem ser utilizadas para serviços personalizados.

## 2. Uso das Informações
Usamos as suas informações para:
- Processar comandos e fornecer os serviços do bot;
- Gerir configurações específicas do servidor.

## 3. Retenção de Dados
Os dados são armazenados apenas pelo tempo necessário para realizar as funções do bot e são excluídos quando não forem necessários.

## 4. Partilha de Dados
Não partilhamos as suas informações com terceiros, exceto para utilizar os serviços fornecidos por terceiros.

## 5. Segurança
Tomamos medidas para proteger suas informações contra acessos não autorizados.

## 6. Alterações nesta Política
Podemos atualizar esta Política de Privacidade periodicamente. A versão mais recente estará sempre disponível aqui.
